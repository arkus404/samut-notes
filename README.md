# สมุด

แอปโน้ตมินิมอล แก้ไข้มาร์กดาวน์ ค้นหาทันที เก็บในเบราว์เซอร์

## เปิดใช้

- โหลด [index.html](index.html) ในเบราว์เซอร์ (ต้องมี `app.js` อยู่ไฟล์เดียวกัน)
- หรือเปิดจากโฮสต์: [cdn.jsdelivr.net](https://cdn.jsdelivr.net/gh/arkus404/samut-notes@main/index.html)

เพื่อใช้งานถาวร: GitHub → Settings → Pages → Deploy from branch `main` / root

## ปุ่มลัด

| ปุ่ม | การทำงาน |
| --- | --- |
| Ctrl/Cmd + N | โน้ตใหม่ |
| Ctrl/Cmd + F หรือ / | ค้นหา |
| Ctrl/Cmd + E | สลับตัวอย่างมาร์กดาวน์ |
| Ctrl/Cmd + \\ | แถบข้าง |
| Ctrl/Cmd + Backspace | ลบโน้ต |
| Ctrl/Cmd + / | แสดงปุ่มลัด |
| Alt + ↑ / ↓ | โน้ตก่อนหน้า / ถัดไป |
| Esc | ปิดแผง / ล้างค้นหา |

ข้อมูลอยู่ใน localStorage ของเบราว์เซอร์ — ไม่ส่งไปเซิร์ฟเวอร์
